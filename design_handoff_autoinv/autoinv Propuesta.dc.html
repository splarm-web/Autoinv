04

Arquitectura propuesta

Estructura modular, lista para crecer: SQLite→PostgreSQL sin refactor, almacenamiento local→nube, y el generador de facturas como módulo intercambiable (un diseño = una carpeta). Referencia para implementación.

Backend · FastAPI
backend/
├─ app/
│  ├─ main.py            arranque, CORS, routers
│  ├─ core/
│  │  ├─ config.py       .env: DB_URL, FILES_ROOT
│  │  ├─ security.py     hash + JWT
│  │  └─ database.py     SQLite → Postgres
│  ├─ models/            ORM: user, expense, invoice
│  ├─ schemas/           Pydantic in/out
│  ├─ api/routers/       auth · expenses · invoices
│  │                     dashboard · export
│  ├─ services/
│  │  ├─ ocr_claude.py   visión Claude → JSON
│  │  ├─ storage.py      ficheros (local→nube)
│  │  └─ export_zip.py   ZIP + CSV
│  └─ invoicing/         ← módulo desacoplado
│     ├─ base.py         InvoiceData + Renderer
│     └─ designs/
│        └─ minimal/     1 diseño = 1 carpeta
│           ├─ render.py implementa Renderer
│           └─ template.html
└─ data/
   ├─ app.db
   └─ files/<user_id>/  justificantes + PDFs

│  │  ├─ invoices/        alta + preview

└─ vite.config.js
Esquema de base de datos
users          id · email · password_hash · created_at
               legal_name · nif · address
               default_vat (21) · irpf_rate (15) · invoice_number_format ('YYYY-NNN')
               settings_json          ← config extensible (futuro)

expenses       id · user_id→users
               date · amount · vat_rate · vat_amount
               supplier · concept · category
               source   (manual | foto | pdf | email-futuro)
               file_path              ← justificante original
               created_at

invoices       id · user_id→users
               number · date · due_date
               client_name · client_tax_id · client_address
               subtotal · vat_total · irpf_total · total
               pdf_path · created_at

invoice_lines  id · invoice_id→invoices
               description · quantity · unit_price · vat_rate · line_total

Siguientes pasos

1 · Validar factura. Dime qué ajustar: jerarquía, datos obligatorios (registro mercantil, etc.), tinta de acento.
2 · Flujo de captura. Prototipar foto/PDF → extracción → formulario editable (móvil).
3 · Resto de pantallas. Listado con filtros, alta de factura, ajustes y exportación.
